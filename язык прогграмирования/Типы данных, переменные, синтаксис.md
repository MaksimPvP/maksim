Чтобы проверить тип некоторого значения, используется функция type(). Внутри скобок помещается значение или переменная 


``

Базовые типы данных:
- int - целые числа 
- str(string) - текстовые строки , всегда пишутся в кавычках!!!
- float - дробные числа 
- bool - логические значение True или False
Литерал - запись фиксированного значения прямо в коде.
Значение - это конкретная информация , которую хранит объект, переменная или выражение.
Объект - экземпляр класса, который может содержать данные и методы для работы с этими данными.
###Переменные 
Переменная - именованная  ссылка на объект в памяти компьютера. Сама переменная не хранит значения , а лишь указывает , где лежит объект, поэтому две переменные могут указывать на один объект .



Запись состоит из следующих частей:
- Идентификатор (имя). Начинается с буквы или знака __ , далее допускаются буквы, цифры и знак __.
Python - регистрозависимый , т.е name и NAME - два разных имени. Использование ключевых слов в названии переменных запрещено.
- Оператор присваивания. выполняет функцию связывания имени с объектом. Записывается как =.
- Объект, задаваемый литералом или некоторым значении.
